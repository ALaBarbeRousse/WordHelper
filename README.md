# WordHelper

Application aimed at foreign words study.

### База данных
Приложение использует СУБД Postgresql. Для того, чтобы оно адекватным образом работало,
необходимо установить её на локальный компьютер: sudo apt install postgresql.
После установки создать в ней базу данных words. Логин и пароль к базе данных (postgres/postgres) прописаны в application.yml.

### Ролевая модель
По всей видимости, придётся всё-таки сделать что-то вроде ролевой модели.
Прямо сейчас представляются три роли - STUDENT, EDITOR и ADMIN.
STUDENT обладаем минимальными правами - только чтение готовых словарей и CRUD
подборок. Именно эта роль выдаётся пользователю при регистрации.
EDITOR - создаёт, корректирует и удаляет словарные статьи.
ADMIN - управляет пользователями (CRUD)
